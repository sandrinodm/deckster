## Unreleased

### Diagram design controls

Brands can set connector widths and patterns, drawing alignment, node sizes, subtitle and note typography, and icon borders. Slides can override placement, node dimensions and connector strokes, and use bundled or HTTPS image icons. Asynchronous calls, replies and error connectors still draw dashed. Timelines use the brand's regular width when the edge stroke is a named step. PowerPoint keeps diagram shapes editable and embeds image icons as pictures. [Design controls for diagrams](/data-and-diagrams/diagram-design/) · [PR #29](https://github.com/sandrinodm/deckster/pull/29)

### Brand imports and custom layouts

- `deck brand add` cleans SVG artwork while staging a Git import. It warns when it removes unsupported markup and stops the install when an SVG is invalid. [SVG artwork during installation](/brands/use-a-brand/#svg-artwork-during-installation)
- The active brand's `layouts.ts` is read as static data. The build reports MDX slide content outside named slots if the brand layout lacks a body region. [Write layouts.ts](/brands/brand-layouts/#write-layoutsts) · [MDX body content](/brands/brand-layouts/#mdx-body-content)
- The agent's `new_slide` tool uses the live session's brand when it looks up a layout and scaffolds its example. [Scaffold a slide in the session brand](/ai-agents/mcp-tools/#scaffold-a-slide-in-the-session-brand)
- A PowerPoint export writes two distinct body placeholders for a brand layout mapped to two-content. [Brand layouts in PowerPoint](/brands/brand-layouts/#in-powerpoint)

[PR #31](https://github.com/sandrinodm/deckster/pull/31)

### Choosing layouts and importing templates

The presentation skill pairs each of the 63 built-in layouts with a reason to choose it. The docs show those layouts, step previews and live example decks in Fieldnote. You can compare all five brands in the [brand gallery](/examples/brands/). The brand-import skill shows how to map template placeholders to regions and choose a fallback layout. Both guides explain how to check which diagram and export features the installed CLI supports. [Choose a layout](/reference/layouts/#choose-a-layout) · [Use the skills](/ai-agents/skills/) · [PR #32](https://github.com/sandrinodm/deckster/pull/32)

## v0.7.0

The lookbook adds 24 examples for product demos, pitches, roadmaps and strategy reviews. Eleven reusable layouts, three charts and four interactive demo components have new reference entries. [Explore the examples](/examples/presentation-patterns/) · [PR #26](https://github.com/sandrinodm/deckster/pull/26)

You can now switch decks by their opening slides in the browser and desktop presenter. Brand imports validate layouts before installation and preserve existing brands if a replacement fails. [Release notes](https://github.com/sandrinodm/deckster/releases/tag/v0.7.0) · [Previous releases](/project/releases/#what-changed).

### Credential-safe brand sources

`deck brand add` checks the source before logging it. Invalid addresses are omitted from error messages, and a failed fetch reports the Git step without copying raw Git diagnostics. Use your credential helper or SSH key to fetch a private brand. [Authentication and fetch troubleshooting](/brands/use-a-brand/#authenticate-to-a-private-repository) · [PR #20](https://github.com/sandrinodm/deckster/pull/20)

### Transaction-safe brand installs

`deck brand add` stages a complete brand before publishing it. Installs of the same brand run one at a time. On retry after an interruption, the installer restores the previous brand if publication was incomplete. If publication finished, it keeps the new brand and cleans up the backup. If recovery is blocked, the error gives the saved copy's location. [Recover an interrupted replacement](/brands/use-a-brand/#recover-an-interrupted-replacement) · [PR #21](https://github.com/sandrinodm/deckster/pull/21)

### Brand layout validation before install

The importer checks `layouts.ts` against the layout catalog before installing or replacing a brand. Errors leave the installed brand in place, and warnings identify the file and field to fix. [Layout checks during installation](/brands/check-a-brand/#layout-checks-during-installation) · [PR #23](https://github.com/sandrinodm/deckster/pull/23)

### Browser deck chooser

Run `deck dev` without a deck argument or `DECK` in a workspace with several decks. The command prints a chooser URL where you can pick a deck by its title, folder name or a preview of its first visible slide. This includes workspaces with a `hello` deck. [Choose a deck in your browser](/get-started/workspace-layout/#choose-a-deck-in-your-browser) · [PR #22](https://github.com/sandrinodm/deckster/pull/22)

### Desktop presentation gallery

`deck present` opens the workspace gallery when several decks are available and neither a deck argument nor `DECK` is set. Choose a deck to start the presentation, then return to the gallery to switch talks. The display options still apply to the audience and presenter windows. [Choose a deck in the desktop gallery](/present/deck-present-and-displays/#choose-a-deck-in-the-desktop-gallery) · [PR #24](https://github.com/sandrinodm/deckster/pull/24)
