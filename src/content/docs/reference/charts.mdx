Use this page to look up the props of a chart or number component: what each takes, its defaults, and the limits `deck lint` holds it to. To pick a chart for a message, start at [choosing a chart](/data-and-diagrams/choosing-a-chart/); this page assumes you know which one you want.

<CatalogIndex kind="charts" />

## How to read an entry

Each entry starts with when to use the component, when to avoid it, the messages it is the right form for (single number, comparison, trend and so on), the shape of its data rows and its limits: the numbers `deck lint` holds it to, such as the most bars or series. `coloredSeries` in a limit is the size of the brand's categorical palette, counted without the series a highlight mutes. Then a still of a published slide that uses it, its own props, a line naming the shared props it also takes, and an example in MDX. A prop name a chart does not take is refused with the closest name ("`value` is not a prop of BarChart; did you mean `y`?").

How `highlight`, `annotations` and `at` work together is on [highlights and annotations](/data-and-diagrams/highlights-and-annotations/); `BigNumber`, `StatRow`, `Progress` and the other number components are explained on [number components](/data-and-diagrams/number-components/).

`deck charts --json` prints the same catalog, plus two fields this page does not show: `nulls`, how each chart draws a missing value (null, an empty CSV cell, text that is not a number), and `accessibility`. It also gives `native`, the PowerPoint chart `deck export --pptx` builds for the component: `BarChart`, `Comparison`, `Progress`, `Waterfall` and `Funnel` become bar charts; `LineChart`, `Slope` and `Sparkline` line charts; `AreaChart` an area chart; `Donut` a doughnut; `Scatter` a scatter chart; and `Table` a table. `BigNumber`, `StatRow`, `Pictogram`, `Heatmap`, `RetentionCohorts`, `ProfitPool` and `MarketMovement` have no native chart type.

`<Table>` here is the component; the `table` layout has [its own page](/reference/layouts/table/).

### RetentionCohorts

Give each cohort its starting size and a row for each observed age. Write `82` for 82%. A zero prints as `0%`, while an unobserved age stays blank. [Retention cohorts example](/decks/lookbook/#/chart-retention-cohorts)

<PropsTable of="RetentionCohorts" />

### ProfitPool

Use the same currency and scale for every segment’s revenue. Width represents revenue, height measures the contribution margin from zero, and area corresponds to the segment’s contribution profit or loss. [Profit pool example](/decks/lookbook/#/chart-profit-pool)

<PropsTable of="ProfitPool" />

### MarketMovement

Give each observation an ISO date in `YYYY-MM-DD` form. `highlight` names the entity whose positions form a trail. Each peer appears at the dates for which it has data. [Market movement example](/decks/lookbook/#/chart-market-movement)
