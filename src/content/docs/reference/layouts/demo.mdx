Use the `demo` layout to give a product demonstration the space under a one-line title, with room for up to three short notes beside it. The body can hold a mini app, a React widget or an authored demo that runs from the data in the slide.

## When to use it

- **Something has to run in front of the room.** For a still screen, use [`screen`](/reference/layouts/screen/). For a terminal session or code that changes, use [`code`](/reference/layouts/code/).
- **The title says what to watch for**, in one line of up to 48 characters: "Watch Flock build a loop", not "Demo".
- **The body is one element.** Use `<AppFrame>` for a mini app or `<Live>` for a React widget. To stage a product or AI interaction from data in the slide, use `<CommandDemo>`, `<GroundedAnswer>`, `<ReviewDiff>` or `<RunTrace>`. Each has its own deck steps and stills for export. [Demo components](/reference/components/#product-and-ai-demonstrations) · [Live components](/write-slides/live-components/) · [Mini apps](/write-slides/mini-apps/)
- **Notes are a few words each.** `<Aside>` takes up to three bullets and 34 words. What you will say while it runs goes in `<Notes>`.
- **A source or caveat** goes in `<Footnote>`, up to 30 words.

The command palette example shows how to author the available commands and the output each one returns. [Live command palette](/decks/lookbook/#/command-palette) · [Presentation patterns](/examples/presentation-patterns/)

## Common mistakes

- **A fourth note beside the demo.** `deckster lint` holds `<Aside>` to its budget with the `content-budget` rule:

  ```console
  $ deckster lint launch-review
  decks/launch-review/slides/demo.mdx
    error   content-budget (demo): The aside slot holds 4 bullets; its layout allows 3.
            Fix: Cut it to the essentials, split the slide, move detail into speaker notes, or pick a layout made for more content (`deckster layouts`).

  launch-review: 1 error, 0 warnings in 1 slide (1 step checked).
  ```

- **An `<AppFrame>` without a `poster`.** Static mode, exports and offline runs show the poster, so leaving it out is a `schema` error: "`<AppFrame>` needs `poster`: What static mode, exports and offline runs show."
- **An app that does not exist.** `app="dispatch-sim"` needs `decks/<deck>/apps/dispatch-sim/index.html`. Without it, `deckster lint` reports a `schema` error and tells you to run `deckster new app <deck> dispatch-sim`.
- **Only an `<Aside>`.** The body is required: a slide with notes and no demo is a `schema` error, "The demo layout needs content outside its slot tags."
