The team can start implementing returns proof while it is still figuring out how to enroll shops. Comparing two reviews on one hill makes that difference visible.

## Author the slide

Name both review dates and give each of three `scopes` a previous and current position from 0 to 100. The rising side represents discovery, 50 means the approach is known, and the descending side represents execution. With `reveal: true`, the slide opens with the earlier positions and one advance reveals the current positions. Use `takeaway` to explain the decision the movement supports.
