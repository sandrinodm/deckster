Show where the delivery deadline appeared in the notebook and where it landed in Dispatch. Matching labels let the audience find the same information in two views.

## Author the slide

Supply 16:9 `sketch` and `finished` images. Write two `annotations`. Each label has one point on each image in percentages from its top-left corner. Leave room above and to the right of each pin for the label. With `reveal: true`, the finished image and its pins appear on the first advance. Write the consequence for the user in `result`.
