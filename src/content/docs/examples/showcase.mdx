The showcase is "Slides an agent can write", a 45-slide talk about deckster built with deckster. Use this page to find the slide that shows a technique, open it in the built deck, and read or copy its source.

<DeckEmbed deck="showcase" slide="cover" />

The whole deck is at [/decks/showcase/](/decks/showcase/). It uses 23 of the 32 layouts; ten of the sixteen chart and number components; flow, sequence, layers, cycle and tree diagrams and an imported SVG; code, video, a Lottie animation and two live React demos. Its `deck.config.ts` sets `duration: '45m'`, and every slide has speaker notes and a time `budget`.

**The content is illustrative.** Halden, its people, its clients and every Halden number are fictional, and each chart of Halden data says so in a footnote. The portraits and logos are drawn stand-ins. Numbers about deckster itself (layouts, charts, rules, terminal output) were read from the repository.

## Run it or copy from it

The deck is a folder in the repository, `decks/showcase/`. Besides `slides/` (42 MDX files and 3 TSX files) it has `lib/` with the React code the TSX slides import, `apps/agent-chat/` with the mini app `chat-demo` shows, and `assets/` with the pictures, video and animation (sources and licences in `assets/CREDITS.txt`). `BRIEF.md` and `OUTLINE.md` are the brief and outline it was written from.

To run it with the npm CLI, copy the folder into your workspace and delete the two files that tie it to the monorepo:

```sh
git clone --depth 1 --branch v0.5.0 https://github.com/sandrinodm/deckster.git ../deckster
cp -R ../deckster/decks/showcase decks/
rm decks/showcase/package.json decks/showcase/tsconfig.json
```

Then it lints clean, as in the repository:

```console
$ deck lint showcase
showcase: no problems in 45 slides (105 steps checked).
```

`deck dev showcase` serves it, mini app included. The PDF button on the `links` slide is a `<Download file="showcase.pdf">`, which links to a file only `deck build showcase --with-exports` writes into `decks/showcase/dist/`.

To copy one slide, take its file from `slides/` and the files it imports from `assets/` or `lib/`, add its id to your `deck.config.ts`, and run `deck lint`.
