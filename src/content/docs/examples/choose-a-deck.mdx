For a first deck, start with [Hello](/examples/hello/). To copy one slide, pick a deck below, open its slide sidebar and find the slide you want. The corresponding source files are in `decks/<deck>/slides/` in the [v0.7.0 examples](https://github.com/sandrinodm/deckster/tree/v0.7.0/decks). Copy any assets or components the slide imports along with its source.

The gallery renders its decks in Fieldnote. A local copy uses the brand in its `deck.config.ts`. To match the gallery, [add Fieldnote](/brands/use-a-brand/#add-a-published-brand) and run `deck dev <deck> --brand fieldnote`. The [brand comparison](/examples/brands/) shows the same slides in all five published brands.

| What you want to build | Open the deck | What to look for |
| --- | --- | --- |
| A first presentation | [Hello](/decks/hello/) | Four slides with notes, steps, an image and a TSX example. |
| A talk about how deckster works | [Showcase](/decks/showcase/) | Slide structure, presenter tools and the lint workflow in one talk. |
| A slide to copy for a particular layout | [Lookbook](/decks/lookbook/) | All 63 kit layouts in a cargo-bike launch talk. The [lookbook guide](/examples/lookbook/) explains how to find a slide by layout. |
| Variations on a layout | [Layouts](/decks/layouts/) | Compare layout options within one canopy programme presentation. |
| A branded template | [Brand layouts](/decks/brand-layouts/) | Fieldnote cover, section, photo and columns layouts. The [brand layouts guide](/brands/brand-layouts/) explains their fallbacks. |
| An illustrated public talk | [Exemplars](/decks/exemplars/) | Follow the argument for street trees from the opening through the evidence to the close. |
| A chart that answers a question | [Data stories](/decks/data-stories/) | Highlights, comparisons and number components in a support performance review. |
| A system or process diagram | [Diagrams demo](/decks/diagrams-demo/) | Stepped flows, sequence diagrams, timelines and trees. |
| Code, video or motion | [Components](/decks/components/) | Code highlights, diffs, terminal output and cued media. |
| An interactive demo | [Apps demo](/decks/apps-demo/) | Compare an inline widget with an app driven by slide steps and a recorded fallback. |

To run a deck locally, follow the [Showcase copying instructions](/examples/showcase/). The Brand layouts deck requires Fieldnote, which supplies its four template layouts.
