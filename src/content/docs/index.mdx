deckster is a code-first slide framework: one MDX or TSX file per slide, typed layouts and brands, and a `deckster` CLI that serves, lints, screenshots, exports and presents your decks. It is built for slides an AI agent writes and a person reviews, with `deckster lint` checking every step of every slide in between.

<DeckEmbed deck="showcase" slide="lint-path" step={0} />

This showcase slide uses Fieldnote, the brand used for the site's slide previews. Click it and step through with the arrow keys to follow a packet from the deck through Chromium and the rules, then see the findings come back clean.

A brand changes how every slide looks without touching the slide files. This is the showcase deck's `cover` slide in each of the five published brands; only `default` ships with the CLI, and [Use a brand](/brands/use-a-brand/) shows how to add the others:

## Start

With Node.js 26 or later:

```sh
npm install --global @deckster/cli
mkdir talks && cd talks
deckster new launch-review --title "Launch review" --duration 20m
deckster dev launch-review
```

The [quickstart](/get-started/quickstart/) walks through each command and what it prints. [Overview](/get-started/overview/) explains what deckster is and what it needs.
