The change that made the same-hour window work was one line. Flock used to batch every five minutes; now it batches every 90 seconds, so a drop waits at most a minute and a half before it is on a loop. The line was the easy part: Hana Sato's team first had to make the solver plan a hub's loops inside that time.
</Notes>
