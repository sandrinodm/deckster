```ts
const drop = await wren.drops.create({
  pickup: 'hub:old-town',
  dropoff: '14 Weir Street',
  window: { kind: 'two_hour', from: '14:00' },
});
```

<Aside>
- Leave it out for the same hour
- `two_hour` starts on any hour from 8 am to 6 pm
- `evening` is 6 to 9 pm
</Aside>
