<Terminal title="~/brightloaf">
  <Cmd>wren quote --dropoff "14 Weir Street" --window same_hour</Cmd>
  <Out tone="muted">€3.10 · at the door by 09:24</Out>
  <Cmd>wren drops create --dropoff "14 Weir Street"</Cmd>
  <Out tone="success">drp_7Hq2 booked · batching</Out>
  <Cmd>wren drops watch drp_7Hq2</Cmd>
  <Out tone="muted">08:42 batched into loop 14 with Aoife</Out>
  <Out tone="success">09:21 delivered, 3 minutes early</Out>
</Terminal>

<Aside>
- The same API key as the SDK
- `--json` on every command, for scripts
</Aside>

<Notes>
