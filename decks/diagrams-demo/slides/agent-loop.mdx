<Notes>
Five clicks, five moves. The question arrives; the agent asks the model what to do; the model says look up the order; the agent calls the order tool, then the tracking tool, each answer coming back as a ring; then it answers the customer.

Every call goes through the agent: the model never touches a tool directly. That is the property that lets us log and limit every action.
</Notes>
