  <Journey at={1} path="browser cdn gateway orders db" back focus />

<Notes>
Walk the request one hop per click. The browser hits the CDN, which forwards the API call to the gateway; the gateway authenticates and hands it to the orders service, which reads the order from Postgres. Then the response comes back the same way.

The cache and the event stream dim while the request travels: they are not on this path.
</Notes>
