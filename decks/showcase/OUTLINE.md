# Outline: Slides an agent can write

Illustrative content: Halden and its numbers are fictional; the framework's own numbers are real. The outline was not reviewed by a person before the build.

## Storyline

1. A slide is a file, the brand owns every pixel, and a linter tells the author what is wrong.
2. That trades free placement for a brand that holds by construction and a fit that is measured.
3. A layout is a contract (fields, slots, budget, variants), so a slide file never says how it looks.
4. Evidence components make the point: charts with one highlight, diagrams that move, code, media, live apps.
5. A deck rebrands with one line, and the same slides pass in both brands because budgets count content.
6. Lint renders every step in a browser and names the file, the rule and the fix, so people and agents run the same loop.
7. Reviewers comment in the browser, an agent edits only content through a working copy, and the presenter window paces the talk.
8. The same deck becomes a PDF and an editable PowerPoint file, most of it native shapes.
9. Start with four commands, or hand the first draft to an agent.
