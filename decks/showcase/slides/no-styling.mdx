## What a slide file never contains

<Step at={1}>
- A colour: surfaces and roles belong to the brand
</Step>

<Step at={2}>
- A type size: the layout picks the step and fits it
</Step>

<Step at={3}>
- A position: slots place content inside the margins
</Step>

<Step at={4}>
- A workaround: lint reports raw values as `off-brand`
</Step>

<Notes>
Four things you will not find in any file of this deck. [click] No colour. [click] No type size. [click] No position. [click] And if someone sneaks one in, the linter calls it off-brand and says which token to use.

This is the designer's half of the deal: the brand cannot be overridden from a slide.

Transition: so how much can you say with only layouts and components?
</Notes>
