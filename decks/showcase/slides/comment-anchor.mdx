<Notes>
Tomás presses c, clicks the thing he means, and types. The comment is saved as a file next to the deck, with the source line of the element he clicked.

Then I edit the slide, so the line moves. The comment has four honest answers. [click] ok: still there. [click] moved: found elsewhere. [click] guessed: reworded, here is the closest match, please check. [click] lost: I only know the file.

An agent reads the same list as JSON, with a screenshot per comment.

Transition: and the agent can also sit next to the slide.
</Notes>
